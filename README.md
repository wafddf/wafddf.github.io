# Walaa Alyaseen — Personal Portfolio

A responsive trilingual portfolio website in English, Turkish and Arabic. Built as a single static HTML page with embedded CSS and JavaScript.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait a few minutes for GitHub Pages to publish.

Expected website URL: https://wafddf.github.io/

The site uses an abstract CSS illustration instead of a personal photograph and avoids unverified performance claims.
